# MyHub - Personal Daily Dashboard

[![Integration level](https://dash.yunohost.org/integration/myhub.svg)](https://dash.yunohost.org/appci/app/myhub)

> *This package allows you to install MyHub quickly and simply on a YunoHost server.
If you don't have YunoHost, please consult [the guide](https://doc.yunohost.org/admin/get_started/install_on/) to learn how to install it.*

## Overview

MyHub is a personal daily dashboard that displays weather and sports information in a clean, dark-themed interface.

### Features

- **Weather**: Current conditions and 3-day forecast powered by Open-Meteo (free, no API key needed)
- **AI Weather Summary**: Natural-language weather tips generated by opencode
- **Sports**: Recent match results for Cruzeiro and Seleção Brasileira (optional, requires API-Football key)
- **Auto-refresh**: Dashboard regenerates daily at 5:00 AM via systemd timer
- **Responsive**: Works on desktop and mobile
- **Minimal**: No database, no PHP — just a static HTML file

**Shipped version:** 1.0~ynh1

## Disclaimers / important information

- Weather city is configured during installation (resolved via Open-Meteo geocoding)
- Sports section requires a free API key from https://api-football.com (optional — can be left empty)
- The systemd timer runs at 5:00 AM local time with up to 5 minutes random delay
